### About

I'm a dual-degree engineer (AI/ML at GGSIPU + Data Science at IIT Madras) building applied AI systems — RAG pipelines, LLM-powered apps, and ML models for hard, imbalanced real-world data. I also ship full-stack products end to end when an idea needs a working demo, not just a notebook.

Currently looking for **AI/ML and Gen AI engineering roles** where I can work on production-grade systems.

### What I'm working on

- **Comment Category Prediction** — Multiclass ML competition, ranked **388/2,744 (Top 15%)**, Macro F1 of 0.8627, on extreme class-imbalanced text data
- **Finsights** — Full-stack personal finance tracker with LLM-powered natural language queries over spending data
- **DeVahan** — Web3 vehicle ownership platform with role-based dashboards, smart contracts, and IPFS-backed metadata storage
- **PramaanNFT** — Smart contract-backed property validation system with NFT minting and PIN-based auth
